# G2 / D03-W 编辑器性能实测

- 日期：2026-10-24
- 设备：Xiaomi 14 Pro（2304FPN6DC / Android 16 / 1440×3200 / 120Hz，debug 构建）
- 服务器：`http://192.168.2.102:18081`（0.6.3 @ `85ec97c`），局域网直连
- fixture：`tools/d03w_fixture.py gen`（字节口径，见下方“口径”），21 份文档，SHA-256 见 [`../fixtures.json`](../fixtures.json)
- 埋点：`EditorPerf`（logcat tag `EditorPerf`），字段 `editor-open` / `editor-input-visible` / `editor-save`（含 `draftWindow`）
- 测量方式：`adb shell input` 注入按键与文本，`adb shell dumpsys meminfo` 取 PSS，单机单轮采样

## 口径说明（重要）

`06 §4` 冻结的 D03-W 原文为「~50KB UTF-8（约 2.5 万字符）」，中文下两者不自洽（UTF-8 中文 1.7 万字符即达 50KB）。本轮**按字节口径**生成并测量，`06` 已登记为待评审人裁定；若改为字符口径，需重新生成 fixture 后复测。

实测 fixture 规模：

| fixture | 字节 | 字符 |
|---|---|---|
| `d03-writing-zh-ch01..10` | 各 51,324 B | 各 17,372 |
| `d03-writing-en-ch01..10` | 51,669–51,734 B | 51,629–51,694 |
| `d03-large-500k` | 512,336 B | 171,928 |

## 结果

### 1. 文档打开（`editor-open`，请求发出 → 正文可编辑）

| 文档 | 字符 | 耗时 |
|---|---|---|
| 标准章（中文 50KB） | 17,372 | **65 ms**（另一次运行 35 ms） |
| 压力文档（500KB） | 171,928 | **145 ms**（另一次运行 126 ms） |
| 语料对照（小文件） | 277 | 60 ms |

### 2. 输入 → 可见（`editor-input-visible`，最后一次按键 → 该帧绘制完成）

| 场景 | n | p50 | p95 | p99 | max |
|---|---|---|---|---|---|
| 标准章 51KB（累计采样） | 150 | 8–11 ms | **17–35 ms** | **46–51 ms** | 79 ms |
| 压力文档 512KB（新进程，纯压力样本） | 100 | 8–9 ms | **26–27 ms** | **54 ms** | 61 ms |

采样方式：`adb shell input keyevent 29` 逐字符注入 60 次触发一次 50 样本汇总；`input text` 批量提交只产生 1–2 个样本，不足以出汇总。

### 3. 保存事务（`editor-save`，草稿落盘 → PUT → 清草稿）

| 场景 | 首次 | 稳态 |
|---|---|---|
| 标准章 51KB | **589 ms** | 249 ms / 197 ms |
| 压力文档 512KB | **2,768 ms** | 651 / 694 / 702 ms |

`draftWindow`（最后一次编辑 → 草稿落盘）实测 **800–1,028 ms**，等于 800 ms 防抖 + 落盘耗时，符合 `AUTOSAVE_DEBOUNCE_MILLIS = 800` 的设计预期。

### 4. 峰值内存（PSS）

| 状态 | TOTAL PSS |
|---|---|
| 编辑器空态（刚进入，无文档） | 170,505 KB |
| 打开标准章 51KB | 192,637 KB（**+22.1 MB**） |
| 打开压力文档 512KB | 246,900 KB（**+76.4 MB**） |

### 5. 对照语料渲染

`d03-writing/corpus.md`（标题、加粗/斜体/删除线/行内代码/链接、有序与无序列表含嵌套、引用、围栏代码块、GFM 表格、图片引用）：

- **预览模式**：全部节点正确渲染（H1/H2、内联样式、两种列表、blockquote、代码块、表格表头与单元格、图片占位）。
- **富文本模式**：只隐藏内联标记（`**`/`*`/`~~`/反引号），块级标记（`#`、`-`、`>`、围栏、表格竖线）仍以原文显示——与当前实现范围一致，已在矩阵 `gap_or_decision` 登记。

## 限制（不构成通过）

- 单机单轮采样，未做多次中位数；`input keyevent` 注入节奏与真实键入不同（每字符约 20–30 ms 间隔），p99 受注入抖动影响。
- 未测滚动帧时间与模式切换耗时（未加对应埋点）；`gfxinfo` 在本机不可用（见 G4 D03 结论）。
- 未做 Web 基线对照：编辑器输入延迟的对照需要 Web harness，本轮未建。
- fixture 以字节口径生成，口径待裁定。
- 测量完成后已删除测试项目中的 `d03-writing/` 目录（22 个文件，含语料对照），未在服务端留下数据。
