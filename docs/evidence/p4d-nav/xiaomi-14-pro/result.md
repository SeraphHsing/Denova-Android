## 1. 起因

NAV-001 的判据是「依次打开全部目的地，默认顺序与唯一高亮对应，且不产生额外模式状态」。P4-C 收口时
9/13 可进入；P4-D 补了 settings（设置页）、automations（自动化）、market（资源市场）之后，
只剩 `versions` 仍是 WIP——版本能力此前只有文档内部的「版本」抽屉承载。

本轮新增 `feature/versions/VersionsScreen.kt`：**复用**同一份 `VersionsContent` + `VersionsViewModel`
（状态 / 列表 / 创建 / diff / 两步恢复），不复制第二套实现；`ActivityNav` 把 `versions` 标为可进入。
宿主没有当前项目时（例如上次打开的书已归档）页面顶部提供「项目 ID + 读取」入口，避免只能看空态。
