## 3. GAM-004 Enter 换行（同轮修复并验证）

真机复现：游戏输入框原为 `singleLine = true`，**回车被吞掉**——既不发送也不换行（输入框显示 `line1line2`），
与「Enter 只换行、点击才发送」的基线不符。

修复：去掉 `singleLine`，改 `minLines = 1 / maxLines = 4`（多行输入，发送仍只走按钮）。

复测：输入 `line1` → 回车 → `line2`，控件文本为 `line1\nline2`（`&#10;`），`send story=` 计数 **0**；
此前每次点击「发送」都只产生 **1** 条 `send story=` 记录（见历次切片日志），即一次点击一次逻辑输入。
