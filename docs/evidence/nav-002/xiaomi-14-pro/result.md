# NAV-002 切页后草稿与滚动保留（真机，草稿通过 / 滚动待补）

- **日期**：2026-10-30
- **设备**：小米 14 Pro（`135babde`），Android 16
- **应用**：`com.denova.novara` Debug（本轮构建）
- **服务器**：`http://192.168.2.102:18081`（后端 0.6.3-b）

## 判据与实测

| 步骤 | 结果 | 证据 |
|---|---|---|
| 编辑器输入后切到写作 Agent | 通过 | 顶栏「写作」进入 `Novara 写作` 页（节点：`session ID / 挂接 / 状态：空闲 / 暂停`） |
| 返回编辑器 | 通过 | 点「返回」回到 `Novara 编辑器`，标签 `ideas.md`、项目 ID、文件路径都还在 |
| 草稿保留（断网构造） | 通过 | 断网后输入 `rr` → 立即切 Agent → 返回编辑器：编辑态仍在，显示「错误 / 保存失败：Failed to connect to /192.168.2.102」（说明内容来自仍在内存的编辑态，而非重新读服务器） |
| 恢复网络后保存 | 通过 | 恢复网络点「保存」→「已保存」×2，内容（含 `rr`）写入服务器 |

## 本轮实现

- `AgentScreen` 的消息列表状态改为 `rememberSaveable(saver = LazyListState.Saver)`：切页返回不再回到顶部（原先每次重建 `rememberLazyListState`）。
- 编辑器正文：`textFieldValue` 仍由 UI 状态（含 caret）驱动，返回时按 `uiState.content + caret` 重建，`BasicTextField` 会把光标滚入可见区。
