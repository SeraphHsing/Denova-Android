# AUTH-004 迟到 401：构造尝试与已取得的链路证据（2026-10-31，未收口）

- **设备**：小米 14 Pro（`135babde`），480dp（`wm density 480`），浅色
- **服务器**：`http://192.168.2.102:18081`（0.6.3-b），客户端经本机延迟代理 `192.168.2.101:18099` 连接
- **代理**：`python tools/g3d_slow_proxy.py --listen 192.168.2.101:18099 --target http://192.168.2.102:18081 --put-delay-ms 20000 --status-delay-ms 20000`

## 1. 已取得的链路证据（真实 401，不是伪造）

23:19 一次完整时序（`adb logcat -s Auth Connection`）：

```
23:19:09.522 I Connection: logout
23:19:12.543 I Connection: logout drain pending=1 drained=false after=3000ms
23:19:29.020 W Auth    : session unauthorized (401) origin=http://192.168.2.101:18099
23:19:49.118 W Connection: session expired, returning to login
```

可以确认的三件事：

1. **旧请求的 401 确实会迟到**：保存请求被代理延迟 20s 转发，服务端在会话已被
   `PATCH /api/settings`（改 `remote_access_password`）吊销之后才处理它，因此返回 401，
   而客户端此时早已退出到登录页。
2. **401 不直接降级**：从 23:19:29 收到 401 到 23:19:49 才出现 `session expired`，
   中间正是 `SessionExpiryConfirmer` 的 status 探测（20s 延迟）。直接降级会在 23:19:29 就发生。
3. **`logout` 的 drain 与世代推进按设计工作**：`drain pending=1 drained=false` 说明退出时确有在途写请求，
   超时后靠 `generation.retire()` 作废其响应。

## 2. 未取得的证据（因此本行仍未回写）

缺的是「**新会话已建立且有效时，迟到的 401 / 慢探测结果不能把用户踢回登录页**」这一支：

- 探测返回 `authenticated=true` → 应打印 `late 401 ignored, session still valid`；
- 探测期间完成登录 → 应打印 `stale 401 confirmation ignored gen=…`；
- 界面应停留在编辑器。

本轮三次尝试都卡在同一处：**在 20s 窗口内没能完成「退出 → 重新登录」**。根因是
`adb shell input text` 在禁用 IME 的情况下会静默丢字符，密码框实际值不完整（例如
`19950725fxx8` 被输入成 11 位），点击「登录」后仍停在登录页；等发现时 20s 窗口已过，
401 到达时用户还没登录，于是走了「确认未认证 → 降级」的正常分支。

## 3. 下一次直接可用的执行顺序

1. 设备：`wm density 480`；确认**所有** IME 已禁用（`ime list -s` 为空；MIUI 上百度输入法也会自动启用）。
2. 代理：`--put-delay-ms 20000 --status-delay-ms 20000`。
3. App 登录并打开文件 → 切富文本 → 点 `H2`（插入模板使 `content != baseContent`，`saveNow()` 才会真正发 PUT）。
4. `PATCH /api/settings` 改 `remote_access_password`（吊销 App 会话）。
5. 顶栏「退出」→ 登录页。
6. **用 `%TEMP%\type_keys.py` 逐键输入用户名与密码**（不要用 `input text`），提交后确认日志出现 `login ok`。
7. 等待 40s，抓 `Auth`/`Connection` 日志：应出现 `late 401 ignored, session still valid`，且界面仍在编辑器。
8. 收尾：`restore_any.py` 把密码改回原值（脚本会逐个试候选并 PATCH 还原），停代理，`wm density reset`，恢复 IME。
